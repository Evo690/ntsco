================================================================================
1. OVERVIEW & CORE CONCEPT
================================================================================
Most coaching institute and testing portals (Allen, FIITJEE, Resonance, PW, etc.)
only show the Top 20 ranks publicly. A student can only see their own scorecard
(marks, rank, percentile) and batch statistics (average marks, topper marks).

This Pseudo-Leaderboard Generator reconstructs a complete, realistic, 100%
monotonically descending leaderboard (Rank 1 to Rank N) from:
  1. Average marks
  2. Topper marks (Rank 1)
  3. At least ONE student result (marks, rank, percentile)
  4. (Optional) Any additional student results or Top 20 entries

The neural network predicts the underlying non-linear exam score distribution
(CDF curve), pins all known anchor points exactly, and smoothly blends the
curve so that:
  Marks(Rank 1) >= Marks(Rank 2) >= Marks(Rank 3) >= ... >= Marks(Rank N)

================================================================================
2. INPUTS REQUIRED
================================================================================
The generator takes four pieces of input data:

A. BATCH STATISTICS:
   - avgMarks      : Batch average marks (e.g., 122.5)
   - topperMarks   : Rank 1 score (e.g., 275)
   - maxMarks      : Total paper marks (default: 300, or 186, 198, etc.)

B. ANCHOR POINTS (Student Results):
   - BARE MINIMUM: Exactly 1 student result in the format:
       { marks: 208, rank: 63, percentile: 89.51 }
     (Rank 1 is automatically added as an anchor from topperMarks).

   - ACCURACY BOOST (Optional):
       Adding 1-2 more student results (e.g., your friend's score) or the Top 20
       leaderboard entries tightens the distribution curve even further.

================================================================================
3. HOW TOTAL NUMBER OF STUDENTS (N) IS CALCULATED
================================================================================
The standard percentile formula used in examinations is:
  Percentile = (1 - (Rank / N)) * 100

Rearranging to solve for total students N:
  N = Rank / (1 - (Percentile / 100))

Example with real test data:
  Rank = 63, Percentile = 89.51%
  N = 63 / (1 - 0.8951) = 63 / 0.1049 = 600.57  ==>  N = 601 students!

If multiple student anchor points are provided, the generator calculates N for
each valid point and takes the median/mean to eliminate minor rounding discrepancies:
  N = Math.round( average(N_1, N_2, ...) )

================================================================================
4. HOW THE MODEL POWERS BOTH FUNCTIONS
================================================================================
The trained RankNet model (output/ranknet/model.json + group1-shard1of1.bin)
natively powers BOTH tasks:

1. Normal Function (Score -> Percentile & Rank):
   - Feed the student's score, test average, topper, and max marks.
   - RankNet directly evaluates:
       percentile = RankNet(score, avg, topper, maxMarks)
       estimated_rank = round(N * (1 - percentile/100))

2. Reverse Leaderboard Function (Rank 1..N -> Predicted Marks across all students):
   - Since RankNet is strictly monotonic with respect to score (higher marks
     always yield higher percentiles), we invert RankNet using Vectorized
     Grid Lookup:
     In ONE single forward pass (< 3ms in TensorFlow.js), RankNet evaluates
     a grid of candidate scores (from 0 to topper). This creates an exact
     continuous lookup map from Percentile to Marks!
   - Every rank r = 1..N has target percentile: P_r = 100 * (1 - r/N).
   - The marks for all N ranks are retrieved instantly with zero delay!
   - This means ONE SINGLE lightweight model handles both functions!

================================================================================
5. COMPLETE MATHEMATICAL & CALIBRATION PIPELINE
================================================================================
Step 1: Compute N from the anchor point(s):
        N = round(rank / (1 - percentile/100))
Step 2: Generate all ranks: r = 1, 2, 3, ..., N.
Step 3: Evaluate RankNet over candidate scores in a single vectorized forward
        pass to construct the inverted marks-at-percentile curve.
Step 4: Anchor Pinning & Residual Calibration:
        For every known anchor (Rank 1 = topper, Rank 63 = 208, etc.), compute:
          residual_k = actual_score_k - model_score(rank_k)
        Smoothly interpolate residual(r) between anchors using linear/cubic interpolation.
        calibrated_score(r) = model_score(r) + residual(r)
Step 5: Enforce Strict Monotonicity:
        Leaderboard marks can never increase as rank gets worse.
        From r = 2 to N:
          score(r) = Math.min(score(r - 1), score(r))
Step 6: Clamping:
        Clamp all scores between minimum possible (e.g. 0) and topperMarks.

```javascript
/**
 * PseudoLeaderboardEngine
 * Client-side TensorFlow.js pseudo-leaderboard generation with anchor calibration.
 */
class PseudoLeaderboardEngine {
  constructor() {
    this.rankNet = null;
    this.meta = null;
  }

  /**
   * Load the TensorFlow.js model and metadata.
   * @param {string} basePath - Path to web_model folder (e.g., './web_model')
   */
  async init(basePath = './web_model') {
    try {
      const metaRes = await fetch(`${basePath}/meta.json`);
      this.meta = await metaRes.json();
    } catch (e) {
      console.warn("Could not load meta.json, using defaults.");
    }

    try {
      const rankNetPath = (await fetch(`${basePath}/ranknet/model.json`).then(r => r.ok).catch(() => false))
        ? `${basePath}/ranknet/model.json`
        : `${basePath}/model.json`;
      this.rankNet = await tf.loadLayersModel(rankNetPath);
      console.log("RankNet loaded successfully for normal prediction and reverse leaderboard generation.");
    } catch (e) {
      console.error("Failed to load RankNet model:", e);
    }
  }

  /**
   * Calculate total students N from anchor points.
   */
  calculateN(anchorPoints) {
    const estimates = [];
    for (const pt of anchorPoints) {
      if (pt.rank && pt.percentile && pt.percentile > 0 && pt.percentile < 100) {
        const est = pt.rank / (1.0 - (pt.percentile / 100.0));
        if (est > 0 && isFinite(est)) estimates.push(est);
      }
    }
    if (estimates.length === 0) return 500; // fallback if no percentile provided
    estimates.sort((a, b) => a - b);
    const median = estimates[Math.floor(estimates.length / 2)];
    return Math.max(10, Math.round(median));
  }

  /**
   * Generate Full Pseudo Leaderboard.
   * @param {Object} params
   * @param {number} params.avg - Batch average marks
   * @param {number} params.topper - Rank 1 marks
   * @param {number} [params.maxMarks=300] - Total exam marks
   * @param {Array<{rank: number, marks: number, percentile?: number}>} params.anchorPoints
   * @param {number} [params.overrideN] - Optional manual override for total students
   * @returns {Promise<Array<{rank: number, marks: number, percentile: number, isAnchor: boolean}>>}
   */
  async generateLeaderboard({ avg, topper, maxMarks = 300, anchorPoints = [], overrideN = null }) {
    if (!avg || !topper || topper <= avg) {
      throw new Error("Invalid parameters: topper must be greater than avg.");
    }

    // 1. Calculate N
    const N = overrideN || this.calculateN(anchorPoints);

    // 2. Consolidate Anchors
    const anchorMap = new Map();
    // Rank 1 is always anchored to topper
    anchorMap.set(1, Number(topper));

    for (const pt of anchorPoints) {
      if (pt.rank && pt.marks != null && pt.rank >= 1 && pt.rank <= N) {
        anchorMap.set(Math.round(pt.rank), Number(pt.marks));
      }
    }

    // 3. Inference for all Ranks 1 to N
    const difficulty = avg / maxMarks;
    const topper_norm = topper / maxMarks;
    const maxMarks_norm = maxMarks / 300.0;
    const gap = topper - avg;

    const rawScores = new Float32Array(N);

    if (this.rankNet) {
      // High-performance vectorized grid inversion (1 single forward pass for all ranks)
      const step = 0.5;
      const numGrid = Math.floor(topper / step) + 1;
      const gridScores = new Float32Array(numGrid);
      const gridInputs = [];
      const k = -4.6774 * difficulty + 4.5740;
      const sigma = k > 0 ? gap / k : 1.0;

      for (let i = 0; i < numGrid; i++) {
        const s = i * step;
        gridScores[i] = s;
        const z = sigma > 0 ? (s - avg) / sigma : 0.0;
        const x_norm = gap > 0 ? (s - avg) / gap : 0.0;
        gridInputs.push([z, Math.max(0.01, Math.min(x_norm, 1.0)), difficulty, maxMarks_norm]);
      }

      const gridTensor = tf.tensor2d(gridInputs);
      const gridPreds = await this.rankNet.predict(gridTensor).data();
      gridTensor.dispose();

      // Invert for each rank r via fast in-memory binary search (< 0.5ms total)
      for (let r = 1; r <= N; r++) {
        const targetY = 1.0 - (r / N);
        let low = 0, high = numGrid - 1;
        while (low < high - 1) {
          const mid = (low + high) >> 1;
          if (gridPreds[mid] < targetY) low = mid;
          else high = mid;
        }
        const span = gridPreds[high] - gridPreds[low];
        const frac = span > 1e-6 ? Math.max(0, Math.min(1, (targetY - gridPreds[low]) / span)) : 0;
        rawScores[r - 1] = gridScores[low] + frac * (gridScores[high] - gridScores[low]);
      }
    } else {
      // Statistical fallback if TF.js not loaded yet
      for (let r = 1; r <= N; r++) {
        const y = 1.0 - (r / N);
        rawScores[r - 1] = avg + Math.tan((y - 0.5) * 1.4) * (gap * 0.45);
      }
    }

    // 4. Residual Calibration through Anchors
    const sortedAnchorRanks = Array.from(anchorMap.keys()).sort((a, b) => a - b);
    const residuals = sortedAnchorRanks.map(r => ({
      rank: r,
      res: anchorMap.get(r) - rawScores[r - 1]
    }));

    const calibratedScores = new Float64Array(N);

    for (let r = 1; r <= N; r++) {
      if (anchorMap.has(r)) {
        calibratedScores[r - 1] = anchorMap.get(r);
        continue;
      }

      // Interpolate residual between flanking anchors
      let res = 0;
      if (residuals.length === 1) {
        res = residuals[0].res;
      } else if (r <= residuals[0].rank) {
        res = residuals[0].res;
      } else if (r >= residuals[residuals.length - 1].rank) {
        res = residuals[residuals.length - 1].res;
      } else {
        // Linear interpolation between left and right anchor
        let left = residuals[0];
        let right = residuals[residuals.length - 1];
        for (let i = 0; i < residuals.length - 1; i++) {
          if (residuals[i].rank <= r && residuals[i + 1].rank >= r) {
            left = residuals[i];
            right = residuals[i + 1];
            break;
          }
        }
        const frac = (r - left.rank) / (right.rank - left.rank);
        res = left.res + frac * (right.res - left.res);
      }

      calibratedScores[r - 1] = rawScores[r - 1] + res;
    }

    // 5. Enforce Strict Monotonicity & Clamping
    calibratedScores[0] = topper;
    for (let r = 2; r <= N; r++) {
      // Current rank marks cannot exceed previous rank marks
      if (calibratedScores[r - 1] > calibratedScores[r - 2]) {
        calibratedScores[r - 1] = calibratedScores[r - 2];
      }
      // Re-pin anchors if monotonicity violated
      if (anchorMap.has(r)) {
        calibratedScores[r - 1] = anchorMap.get(r);
      }
    }
    // Backward pass to ensure anchors didn't create backward inversions
    for (let r = N - 1; r >= 1; r--) {
      if (calibratedScores[r - 1] < calibratedScores[r]) {
        calibratedScores[r - 1] = calibratedScores[r];
      }
    }

    // 6. Build Output Leaderboard
    const leaderboard = [];
    for (let r = 1; r <= N; r++) {
      const finalMarks = Math.max(0, Math.min(topper, calibratedScores[r - 1]));
      const pct = Math.max(0.01, Math.min(99.99, (1.0 - (r / N)) * 100));
      leaderboard.push({
        rank: r,
        marks: Number(finalMarks.toFixed(1)),
        percentile: Number(pct.toFixed(2)),
        isAnchor: anchorMap.has(r)
      });
    }

    return leaderboard;
  }

  // Normal Function: Score -> Percentile & Rank
  async predictPercentileAndRank(score, avg, topper, maxMarks, totalN) {
    if (!this.rankNet) throw new Error("RankNet model not loaded.");
    const difficulty = avg / maxMarks;
    const k = -4.6774 * difficulty + 4.5740;
    const sigma = k > 0 ? (topper - avg) / k : 1.0;
    const z = sigma > 0 ? (score - avg) / sigma : 0.0;
    const gap = topper - avg;
    let x_norm = gap > 0 ? (score - avg) / gap : 0.0;
    x_norm = Math.max(0.01, Math.min(x_norm, 1.0));
    const max_norm = maxMarks / 300.0;

    const inputTensor = tf.tensor2d([[z, x_norm, difficulty, max_norm]]);
    const out = this.rankNet.predict(inputTensor);
    const data = await out.data();
    inputTensor.dispose();
    out.dispose();

    const pct = Math.max(0.01, Math.min(99.99, data[0] * 100.0));
    const rank = totalN ? Math.max(1, Math.round(totalN * (1.0 - pct / 100.0))) : null;
    return { percentile: Number(pct.toFixed(2)), rank };
  }

  async _bisectScore(targetY, avg, topper, maxMarks) {
    let low = Math.max(0, avg - (topper - avg) * 1.5);
    let high = topper;
    for (let step = 0; step < 15; step++) {
      const mid = (low + high) / 2;
      const res = await this.predictPercentileAndRank(mid, avg, topper, maxMarks, null);
      if (res.percentile / 100.0 < targetY) low = mid;
      else high = mid;
    }
    return (low + high) / 2;
  }
}
```

  <tr class="${row.isAnchor ? 'anchor-row' : ''}">

    <td>${row.percentile}%</td>
  </tr>
`).join("");

Step 5: Export to CSV:
----------------------
function downloadCSV(leaderboard, filename = "pseudo_leaderboard.csv") {
  let csv = "Rank,Predicted_Marks,Percentile,Status\n";
  leaderboard.forEach(r => {
    csv += `${r.rank},${r.marks},${r.percentile},${r.isAnchor ? 'Actual_Anchor' : 'Predicted'}\n`;
  });
  const blob = new Blob([csv], { type: "text/csv;charset=utf-8;" });
  const link = document.createElement("a");
  link.href = URL.createObjectURL(blob);
  link.download = filename;
  link.click();
}

8. EDGE CASES & FAQ
================================================================================

Q: What if I don't know the exact batch average?
A: You can use the auto-estimate formula:
     avg = topper * (0.35 to 0.45) depending on paper difficulty.
   Or optimize avg so that RankNet(student_marks) matches student_percentile.

Q: What if two students have the same marks?
A: Real tests have ties at identical scores. The monotonic smoothing naturally
   allows scores to plateau across consecutive ranks, matching real examination
   cluster patterns.

Q: Can this be used for non-300 marks exams (e.g. JEE Advanced 186/198 marks, NEET 720)?
A: Yes! The inputs are normalized by maxMarks (difficulty = avg/maxMarks,
   maxMarks_norm = maxMarks/300.0, topper_norm = topper/maxMarks). Set maxMarks: 186
   and it will scale seamlessly.

Q: How long does generating 1,000 ranks take?
A: Less than 5 milliseconds on modern browsers using TensorFlow.js GPU/WebGL backend.
